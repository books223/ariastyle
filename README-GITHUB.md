# آریاستایل | AriaStyle

نسخه فرانت‌اند فروشگاه آریاستایل؛ آماده انتشار رایگان با GitHub Pages.

## انتشار با GitHub Pages

1. در GitHub یک repository جدید بسازید. برای آدرس ساده‌تر می‌توانید نام آن را `ariastyle` بگذارید.
2. فایل ZIP را روی رایانه استخراج کنید.
3. تمام محتویات این پوشه (خود فایل‌ها و پوشه‌ها، نه پوشه والد) را در ریشه repository بارگذاری کنید؛ `index.html` باید در ریشه باشد.
4. در صفحه repository وارد **Settings → Pages** شوید.
5. در قسمت **Build and deployment** گزینه **Deploy from a branch** را انتخاب کنید.
6. Branch را روی `main` و پوشه را روی `/(root)` قرار دهید و **Save** را بزنید.
7. پس از پایان انتشار، نشانی نمایش‌داده‌شده در همان بخش Pages را باز کنید.

## نکات مهم

- فایل `.nojekyll` برای انتشار مستقیم فایل‌ها در GitHub Pages قرار داده شده است.
- این پروژه یک وب‌سایت استاتیک HTML/CSS/JavaScript است؛ صفحات، تصاویر و تعاملات سمت مرورگر در آن اجرا می‌شوند.
- GitHub Pages بک‌اند اجرا نمی‌کند. ورود و ثبت‌نام واقعی، مدیریت موجودی، سفارش‌های پایدار و پرداخت آنلاین تا زمان اتصال بک‌اند فعال نخواهند بود.
- داده‌هایی که با `localStorage` ذخیره می‌شوند فقط در همان مرورگر و دستگاه کاربر باقی می‌مانند.
- برای تغییر سایت، فایل‌ها را در repository به‌روزرسانی کنید؛ GitHub Pages پس از انتشار تغییرات را نمایش می‌دهد.

## اجرای محلی

فایل `index.html` را در مرورگر باز کنید. برای تست دقیق‌تر مسیرها و رفتارها، بهتر است از یک سرور محلی ساده استفاده کنید.


## نکته درباره نقشه سایت (Sitemap)

فایل `sitemap.xml` عمداً تا زمان مشخص شدن آدرس نهایی GitHub Pages ساخته نمی‌شود.
بعد از انتشار، باید آدرس واقعی مخزن (مانند `https://USERNAME.github.io/ariastyle/`) در
نشانی‌های sitemap قرار بگیرد و سپس خط `Sitemap:` به `robots.txt` اضافه شود.
آدرس نمونه یا دامنه‌ی فرضی را منتشر نکنید.

فایل `.htaccess` برای بعضی هاست‌های Apache نگه داشته شده است؛ GitHub Pages آن را اجرا نمی‌کند
و برای انتشار در GitHub Pages نیازی به تنظیم آن نیست.
